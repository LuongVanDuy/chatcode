ChatGPT connection

ChatGPT is the AI. This app only exposes controlled MCP tools for your local projects.

STARTING

Use it in ChatGPT

  1. Add at least one project on the left.
  2. Copy the MCP URL from this page.
  3. In ChatGPT, create/add your custom MCP app/plugin and paste the URL.
  4. Back in a chat, ask: “Use Personal ChatCode and list my projects.”

Keep this app running while ChatGPT is working with your computer. The tunnel URL can change after restart; the secret path protects the MCP endpoint from casual discovery.
